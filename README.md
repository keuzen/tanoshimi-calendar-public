# 楽しみカレンダー

## ローカルでの起動

このフォルダーで次のコマンドを実行し、ブラウザーで `http://localhost:8000/` を開きます。

```sh
python3 -m http.server 8000
```

終了するときは、起動したターミナルで `Ctrl+C` を押します。

## 試作の範囲

- 日付と名前を指定した個人の楽しみを登録し、カレンダーに表示します。
- 登録データは、開いたブラウザーの `localStorage` に保存されます。
- 検索画面に表示されるイベント日程はすべて架空データです。実在イベントの日程取得や掲載は行いません。
- 外部サービスへの通信、ログイン、クラウド同期、通知、他のカレンダーとの連携、広告・課金はありません。
