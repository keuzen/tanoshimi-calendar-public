# 楽しみカレンダー

日付の決まった自分の楽しみを登録し、カレンダーで眺めるための簡易Webアプリです。

公開ページ：https://keuzen.github.io/tanoshimi-calendar-public/

## できること

- 楽しみの名前と日付を登録し、カレンダーと「いちばん近い楽しみ」に表示します。
- 登録した楽しみの削除ができます。

## データの扱い

- 登録した楽しみ（名前と日付）は、開いたブラウザーの中にだけ保存されます。運営者には送信されません。
- 初回は利用規約・確認事項への同意を求めます。同意した後に、Google Analyticsによるアクセス解析を開始します。楽しみの名前や日付、登録した件数は送信しません。
- 任意の匿名アンケート（選択式）があります。回答はGoogleのサービスに送信・保存されます。
- 詳しくは、アプリ内の「利用規約・確認事項」をご覧ください。

## 手元で動かす

このフォルダーで次のコマンドを実行し、ブラウザーで `http://localhost:8000/` を開きます。

```sh
python3 -m http.server 8000
```

終了するときは、起動したターミナルで `Ctrl+C` を押します。
